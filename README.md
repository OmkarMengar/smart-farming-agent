# AgriBot - AI Agent for Smart Farming Advice

An Agentic AI application built for AICTE Problem Statement No. 9 using IBM Bob, IBM Granite models, and IBM watsonx.ai.

## Core Features
* **Crop Advisory Agent:** Provides soil, seasonal, and crop selection guidance.
* **Mandi Price Agent:** Analyzes market trends and crop pricing strategies.
* **Pest & Protection Agent:** Offers organic and safe chemical treatment recommendations.

## Tech Stack
* **LLM Engine:** IBM Granite (`ibm/granite-3-8b-instruct`) via IBM watsonx.ai
* **Framework:** Python Flask
* **Development Environment:** IBM Bob
